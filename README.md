# 饮食日记 · PWA 应用

一个可安装的每日饮食记录应用（PWA）：记录 **蛋白质 / 碳水 / 脂肪 / 热量 / 饮水 / 体重**。

**已部署上线：https://alun99066.github.io/diet-diary/**（手机浏览器打开 → 「添加到主屏幕/安装」，即得独立 App：全屏、离线可用）。

也可以本地双击 `index.html` 直接使用（无需联网，数据存浏览器本地）。

## 部署方式（GitHub Pages）

- 代码仓库：https://github.com/ALUN99066/diet-diary （公开仓库；只含应用代码，**不含任何个人数据**）
- Pages 地址：https://alun99066.github.io/diet-diary/
- **以后更新**：改完 `index.html` 后在本目录执行

  ```
  git add -A && git commit -m "更新说明" && git push
  ```

  Pages 会自动重新发布，1 分钟左右生效。页面是网络优先策略，用户联网打开即拿到新版本。

## 部署到自己的服务器（备用方案）

若要换到自己的服务器：把 `index.html`、`manifest.webmanifest`、`sw.js` 和 4 个图标文件上传到同一目录，**必须 HTTPS**，其余步骤相同（手机浏览器打开 → 添加到主屏幕）。

## 功能

- **记录页**
  - 点日期打开**日历**，自由选择日期（支持跨月；最多选到今天，未来日期不可选），也可用 ‹ › 翻天 / 回到今天
  - 饮食：添加食物（名称、数量、总克数、餐次、蛋白/碳水/脂肪/热量）；**营养数据按「每份」填写，数量填 N 时自动合计为 N 份总量**（弹窗里有实时「总计」预览；数量留空则按所填数值直接记录）；热量留空时按「蛋白×4 + 碳水×4 + 脂肪×9」自动计算；可编辑、删除；可勾选「保存为常用食物」下次一键填入
  - 餐次：按 **第一餐、第二餐、第三餐…** 编号，**每餐右侧 ＋ 直接添加该餐食物**（餐次固定不可选），底部「**加餐**」一键新增一餐，数量不限；**右滑餐次标题删除该餐**（含其中食物，有确认提示；末尾的空餐次直接移除）
  - 饮水：+100 / +250 / +500 快捷键、自定义毫升；「撤销」可回退最近一次添加（刷新后依然有效，最多保留 20 条）
  - 体重：每天一个值，自动显示与上次的差值
- **训练页**
  - 页面上**直接填写**（无需弹窗）：按「**训练部位 → 时长 → 训练计划**」顺序，点「添加」即入记录
  - 训练部位可选常用（胸/背/肩/手臂/腿/臀/核心/有氧/全身/拉伸）或自定义
  - 训练计划为自由文本（如「卧推 4×10 · 上斜哑铃卧推 3×12」），列表里随记录展示
  - 消耗（千卡）可选填，支持「按体重估算消耗」（有氧按 MET 8、全身 6、拉伸 2.5、力量部位默认 5）
  - 常用「部位 + 计划」组合可保存，下次一键填入；点记录的编辑图标可在同一表单里修改（带取消）
- **统计页**
  - 日期范围筛选：近 7 / 14 / 30 天快捷切换，或点起止日期用**日历自定义范围**（最长一年，同样不可选未来）
  - 概览：平均热量与三大营养素、平均饮水、体重变化、供能占比、平均训练与训练消耗
  - 图表：每日热量、每日饮水、每日训练（分钟）柱状图（热量/饮水含目标线）、体重趋势折线图
- **设置页**：修改 5 项目标；导出 JSON 备份 / CSV 表格（Excel 可开，含训练数据）；导入备份迁移数据；清空数据

## 数据说明

- 数据保存在**当前设备、当前浏览器**的本地存储中，不会自动上传到任何服务器（包括你部署应用的服务器——服务器只提供应用文件）。
- 换浏览器或换设备：旧设备「导出备份(JSON)」→ 新设备「导入备份」。
- 清除浏览器缓存/网站数据会丢失记录，建议定期导出备份。
- 同一台设备上用不同浏览器/方式打开（如浏览器标签 vs 主屏 App），数据是各自独立的。
- 旧版本的「早餐/午餐/晚餐/加餐」数据会自动迁移为「第一/二/三/四餐」。

## 文件

- `index.html` — 应用主体（HTML/CSS/JS 单文件）
- `manifest.webmanifest` / `sw.js` — PWA 清单与离线缓存（部署到服务器时必须一起上传；本地双击使用时会被自动忽略）
- `icon-*.png` / `apple-touch-icon.png` — 应用图标
