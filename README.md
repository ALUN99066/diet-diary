# 饮食日记 · PWA 应用

一个可安装的每日饮食记录应用（PWA）：记录 **蛋白质 / 碳水 / 脂肪 / 热量 / 饮水 / 体重**。

两种用法：
- **本地直接用**：双击 `index.html`，浏览器打开即用（无需联网，数据存浏览器本地）。
- **装到手机当 App**：把文件部署到自己的服务器，手机浏览器「添加到主屏幕」——独立图标、全屏运行、离线可用（见下文部署说明）。

## 部署到自己的服务器（PWA 安装）

1. 把以下文件**一起**上传到服务器的同一个目录（可挂在域名根路径或子目录，如 `https://你的域名/diet/`）：

   ```
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
   maskable-512.png
   apple-touch-icon.png
   ```

2. **必须通过 HTTPS 访问**（Service Worker 的硬性要求；localhost 也可以但那只用于本机调试）。
3. 手机浏览器打开网址，各平台安装方式：
   - **Android（Chrome/Edge）**：地址栏会出现「安装」提示，或菜单 → 「添加到主屏幕」；
   - **iOS（Safari）**：分享按钮 → 「添加到主屏幕」。
4. 安装后从主屏图标启动：全屏运行、无地址栏；首次打开后所有资源已缓存，**断网也能记录**（数据存手机本地，随时用设置页导出备份）。

> 提示：以后更新了 index.html，直接覆盖服务器上的文件即可；页面与 manifest 是网络优先策略，用户下次联网打开就会拿到新版本，无需清缓存。

## 功能

- **记录页**
  - 点日期打开**日历**，自由选择日期（支持跨月；最多选到今天，未来日期不可选），也可用 ‹ › 翻天 / 回到今天
  - 饮食：添加食物（名称、餐次、蛋白/碳水/脂肪/热量），热量留空时按「蛋白×4 + 碳水×4 + 脂肪×9」自动计算；可编辑、删除；可勾选「保存为常用食物」下次一键填入
  - 餐次：按 **第一餐、第二餐、第三餐…** 编号，**每餐右侧 ＋ 直接添加该餐食物**（餐次固定不可选），底部「**加餐**」一键新增一餐，数量不限；**右滑餐次标题删除该餐**（含其中食物，有确认提示；末尾的空餐次直接移除）
  - 饮水：+100 / +250 / +500 快捷键、自定义毫升；「撤销」可回退最近一次添加（刷新后依然有效，最多保留 20 条）
  - 体重：每天一个值，自动显示与上次的差值
- **统计页**
  - 日期范围筛选：近 7 / 14 / 30 天快捷切换，或点起止日期用**日历自定义范围**（最长一年，同样不可选未来）
  - 概览：平均热量与三大营养素、平均饮水、体重变化、供能占比
  - 图表：每日热量、每日饮水柱状图（含目标线）、体重趋势折线图
- **设置页**：修改 5 项目标；导出 JSON 备份 / CSV 表格（Excel 可开）；导入备份迁移数据；清空数据

## 数据说明

- 数据保存在**当前设备、当前浏览器**的本地存储中，不会自动上传到任何服务器（包括你部署应用的服务器——服务器只提供应用文件）。
- 换浏览器或换设备：旧设备「导出备份(JSON)」→ 新设备「导入备份」。
- 清除浏览器缓存/网站数据会丢失记录，建议定期导出备份。
- 同一台设备上用不同浏览器/方式打开（如浏览器标签 vs 主屏 App），数据是各自独立的。
- 旧版本的「早餐/午餐/晚餐/加餐」数据会自动迁移为「第一/二/三/四餐」。

## 文件

- `index.html` — 应用主体（HTML/CSS/JS 单文件）
- `manifest.webmanifest` / `sw.js` — PWA 清单与离线缓存（部署到服务器时必须一起上传；本地双击使用时会被自动忽略）
- `icon-*.png` / `apple-touch-icon.png` — 应用图标
